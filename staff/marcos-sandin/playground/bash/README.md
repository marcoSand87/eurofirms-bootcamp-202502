## bash

### intro

GNU Bash o simplemente Bash (Bourne-again shell) es una interfaz de usuario de línea de comandos popular, específicamente un shell de Unix; así como un lenguaje de scripting.

## commands
### pwd
Camino directorio que estoy trabajando.
### mkdir
Crear directorio.
### cd folder-path
Cambia un  directorio.
### ls
Listar un archibo.
### touch
Crear un archibo.
### clear (CTRL +L)
Limpiar la pantalla.
