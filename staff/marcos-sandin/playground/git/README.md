## commands

### git branch 
Muestra todas las ramas
### git status
Muestra el estado del arbol de trabajo.
### git status -u
Te muestra la ruta completa.
### git log
Mostrar los commits
### git switch branch-name
Cambia de rama
### git add file-path
Añade un archibo de commit (consolidar).
### git commit -m message
Guarda los cambios en la rama.
### git restore file-path
Restaura un archibo en la rama.
### git clone repository-url
Clonar repositorio de internet (GitHub).
